## 📖 Sobre

O **DYNAMIC-HOUR** nasceu durante os meus estudos de **TypeScript**, quando decidi recriar um projeto prático que exibe **situações diferentes para cada horário do dia**. ⏰

A ideia é simples: a interface reage à hora atual e mostra um cenário diferente para a manhã, a tarde e a noite, servindo como exercício para praticar tipagem, lógica e manipulação de tempo na linguagem.
